# A response room without another application

The database holds bids, questions, answer sources, library versions and reviews. Claude Code, Codex, OpenCode or Cursor is the operator's door to those records. A command performs one defined operation and shows what changed.

npm run view creates read-only HTML reports. npm run docs creates response packs, reviewer briefs and contact-data review sheets. brand.json supplies the business name, logo path and colours. These are generated reports, not a web application or an editable customer portal.

A screen provides browser permissions, simultaneous editing, mobile forms, offline capture, drag and drop, rich formatting and direct customer workbook editing. This base does not provide those. Local PGlite mode supports one process. A production team installation needs authenticated users, restricted roles and a tested operating process. The software does not fetch source documents, generate answers on its own, fill a procurement portal or submit a tender.

Enterprise DNA scopes the team's forms, identity controls, document formats and connections as part of a custom version. The database remains yours. Omni by Enterprise DNA runs the agreed system for a setup fee followed by a retainer.
